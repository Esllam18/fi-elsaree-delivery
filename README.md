# في السريع Delivery

Flutter delivery and transport platform.

## Engineering baseline
- Flutter, Android + iOS from one codebase
- Clean Architecture + feature-first structure
- Riverpod state management
- GoRouter navigation
- Supabase backend through repository abstractions
- Arabic RTL + English LTR localization from day one
- Responsive UI with compact premium Navy Light/Dark design system
- Dev/production separation and no secrets committed to source control

## Workflow
`main` is the stable review branch. Development work is integrated only when it is ready to be reviewed/run.
